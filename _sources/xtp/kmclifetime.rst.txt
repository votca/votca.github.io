
kmclifetime
***********
Kinetic Monte Carlo of excitons (or other carriers) with site-dependent lifetimes and site exclusion in periodic boundary conditions: lifetime, diffusion length, decay sites, occupations; for one exciton also the exact values
The following table contains the defaults input options for the calculator, The default `OPTIONAL` means this option is switched off, if no input is given. 
`REQUIRED` arguments have to be specified, otherwise an error is thrown.

.. list-table::
   :header-rows: 1
   :widths: 30 20 15 15
   :align: center

   * - Property Name
     - Default Value
     - Description
     - Valid Input
   * - lifetimefile
     - lifetimes.xml
     - | XML file with the lifetime of every site: <lifetimes><site
       | id="0">1e-9</site>...</lifetimes> (seconds; ignored segment
       | types may be left out)
     - 
   * - carriertype
     - singlet
     - State of the hopping carriers
     - | electron
       | hole
       | singlet
       | triplet
   * - ratefile
     - rates.dat
     - File to write the rates
     - 
   * - trajectoryfile
     - trajectory.csv
     - | File with one line per decay: time, lifetime, hops, decay
       | segment, displacement (empty: none)
     - 
   * - numberofinsertions
     - 4000
     - Number of decays to simulate in total (0: exact values only)
     - int+
   * - runs
     - 1
     - | Number of independent runs, in parallel with OpenMP; the
       | decays are distributed over them
     - int+
   * - seed
     - 23
     - Integer to initialise the random number generator
     - int+
   * - numberofcarriers
     - 1
     - | Number of carriers present at a time; a decayed carrier
       | is replaced at once
     - int+
   * - injectionpattern
     - *
     - | Name pattern that specifies on which sites carriers are
       | created. Use the wildcard '*' to create them on any site.
     - 
   * - injectionmethod
     - random
     - | random: creation sites are selected randomly among the
       | free ones
     - random
   * - temperature
     - 300
     - Temperature in Kelvin.
     - float+
   * - occfile
     - occupation.dat
     - | File with the occupation probabilities (summed over carriers)
       | 
     - 
   * - decayprobfile
     - 
     - | Optional file with per-site decay probabilities: local
       | ratios k/(k+out), k/(k+in), the KMC decay fractions and
       | the exact ones for one carrier
     - 
   * - resultfile
     - kmclifetime_results.dat
     - | Main results as 'key value unit' lines in SI units (empty:
       | none)
     - 
   * - exact
     - true
     - | Also compute the exact lifetime, diffusion length and
       | decay probabilities of one carrier (sparse linear systems)
     - bool
   * - waitingtime
     - exponential
     - | Waiting-time method: exponential (static rates) or thinning
       | (time-dependent rates with upper bounds)
     - | exponential
       | thinning
   * - maxrealtime
     - 1E10
     - Maximum wall-clock time of each run
     - float+
   * - ignoresegments
     - 
     - | Segment types (wildcards, separated by commas or spaces)
       | without hops to or from them
     - 
   * - carrierenergy.run
     - false
     - Switch on/off
     - bool
   * - carrierenergy.outputfile
     - energies.csv
     - File to write energies to
     - 
   * - carrierenergy.alpha
     - 0.05
     - Weight of the newest value in the exponential average
     - float+
   * - carrierenergy.outputsteps
     - 10
     - Write after every x hops
     - int+
.. note::
   An *xml* file containing the defaults for the `kmclifetime` calculator can be created via `-p kmclifetime -o FILENAME` command line options `
