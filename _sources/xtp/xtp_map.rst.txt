
NAME
****
**xtp_map** - Part of the VOTCA package

SYNOPSIS
********
**xtp_map** [OPTIONS]

**xtp_map** [--help]



DESCRIPTION
***********

Generates QM|MD topology








OPTIONS
*******
.. highlight:: none

::

  Allowed options:
  
    -h [ --help ]                    display this help and exit
    --verbose                        be loud and noisy
    --verbose1                       be very loud and noisy
    -v [ --verbose2 ]                be extremly loud and noisy
    -t [ --topology ] arg            topology
    -c [ --coordinates ] arg         coordinates or trajectory
    -s [ --segments ] arg            definition of segments and fragments
    -m [ --makesegments ]            write out a skeleton segments file
    -f [ --file ] arg                state file
    -i [ --first-frame ] arg (=0)    start from this frame
    -b [ --begin ] arg (=0)          start time in simulation
    -n [ --nframes ] arg (=1)        number of frames to process
    --guess-bonds                    guess bond connectivity from atom positions 
                                   for topologies without bonds, using VMD's van 
                                   der Waals radii heuristic restricted to atom 
                                   pairs within the same MD molecule. Fails if 
                                   the topology already contains bonds. All 
                                   guessed bonds are written to 
                                   guessed_bonds_report.txt; review them, the 
                                   heuristic can produce false bonds.
