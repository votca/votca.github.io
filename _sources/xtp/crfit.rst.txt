
crfit
*****
Charge-response parametrization of a molecule with xtpdft: the charge-response matrix Pi (Hirshfeld charges), the molecular polarizability and the residual polarizabilities, from the static response to Hirshfeld-localized potentials and uniform fields (coupled-perturbed Kohn-Sham, or finite differences of SCFs). Reads job_name.xyz; closed-shell molecules.
The following table contains the defaults input options for the calculator, The default `OPTIONAL` means this option is switched off, if no input is given. 
`REQUIRED` arguments have to be specified, otherwise an error is thrown.
