
kmctof
******
Time-of-flight kinetic Monte Carlo with site exclusion: carriers are injected in the source region (pulses), hop with Marcus rates and leave at the sink. Every carrier has its own clock; a hop into an occupied site is a null event (exact). Records first arrival and mean transit time per carrier (as grw), the transient current and the collected fraction
The following table contains the defaults input options for the calculator, The default `OPTIONAL` means this option is switched off, if no input is given.
