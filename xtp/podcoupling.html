podcoupling¶

Computes an electronic coupling between two fragments of a SINGLE, already-converged, ordinary (unconstrained, neutral) ground-state DFT calculation, via Projection Operator Diabatization (POD2, Ghan et al.) – separately diagonalizing each fragment’s own donor/acceptor Fock sub-block (in the original AO basis) and reading the coupling off the resulting off-diagonal block, with the paper’s own eqn (10) Lowdin correction applied for the two fragment orbitals’ own non-orthogonality. Suited specifically to COVALENTLY-BONDED fragment pairs, where neither CDFT (a self-consistent, constrained calculation on the intact system) nor FODFT (two separately-converged, ISOLATED fragment calculations, which cannot represent a bond crossing the fragment boundary at all) apply cleanly – for non-bonded fragment pairs, the existing ‘coupling’ tool (DIPRO) remains the established, directly comparable choice. See Baumeier, Kirkpatrick, Andrienko, PCCP 2010, 12, 11103 for the closely related DIPRO method this eqn (10) correction is drawn from, and arXiv:1512.00200 for a direct comparison of POD/POD2 against FODFT and CDFT. The following table contains the defaults input options for the calculator, The default OPTIONAL means this option is switched off, if no input is given. REQUIRED arguments have to be specified, otherwise an error is thrown.
