ewaldbackground¶

Converges the self-consistent polarized background of a periodic system, using the new (non-legacy) Ewald machinery The following table contains the defaults input options for the calculator, The default OPTIONAL means this option is switched off, if no input is given. REQUIRED arguments have to be specified, otherwise an error is thrown.

Default Value

Description

Valid Input

multipoles

output.checkpoint

coulombmethod.alpha

OPTIONAL

coulombmethod.k_max

OPTIONAL

coulombmethod.shape

realspace.screening_factor
