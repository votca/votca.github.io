12.4.1.4.9. latticegen¶

Writes a state file with a surrogate simple cubic lattice hopping model (sites at (i+1/2)a, periodic box, pairs with Marcus parameters), e.g. to test time-of-flight methods. Setup as in Chen, van der Hoorn, Baumeier, arXiv:2405.15836. The following table contains the defaults input options for the calculator, The default OPTIONAL means this option is switched off, if no input is given. REQUIRED arguments have to be specified, otherwise an error is thrown.
