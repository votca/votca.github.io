12.2.1.4.3. ipodcoupling¶

Electronic coupling between two neighbor-list segments by POD2 (projection-operator diabatization) from one ground-state DFT calculation of their H-saturated supermolecule. Follows the IQM workflow (mapping, H-saturation, relaxation, DFT) and then runs PODCoupling instead of dftcoupling/bsecoupling; see podcoupling for the method. The following table contains the defaults input options for the calculator, The default OPTIONAL means this option is switched off, if no input is given. REQUIRED arguments have to be specified, otherwise an error is thrown.
