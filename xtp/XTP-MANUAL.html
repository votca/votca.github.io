Citations¶

Development of this software depends on academic research grants. If you are using VOTCA-XTP, please cite [Baumeier:2024] and the papers of the methods you used.

Every run of xtp_run, xtp_tools and xtp_parallel ends with the list of references for the methods it actually used, in the order of first use, e.g. for a GW-BSE calculation in a polarizable environment

Please cite the methods used in this run:
  [1] Baumeier, Wehner, Renaud, ..., VOTCA: multiscale frameworks ...
  [2] Ruehle et al., Microscopic simulations of charge transport ...
  [3] Thole, Chem. Phys. 59, 341 (1981)
  ...
